

# InAmigos Foundation Website

The InAmigos Foundation Website is a modern, responsive, and visually engaging web platform developed to support the mission of InAmigos Foundation. The website aims to create awareness, encourage volunteering, facilitate donations, and showcase the foundation's efforts in empowering underprivileged communities through education, healthcare, food assistance, and social welfare programs.

### Features

* Responsive and modern UI design
* Interactive Home Page with impactful visuals
* About Us section highlighting mission and vision
* Programs and Initiatives showcase
* Donation section with bank details and QR code support
* Volunteer Registration Form
* Image Gallery for events and activities
* Contact and Social Media Integration
* Mobile-friendly design

### Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

### Objective

To provide a digital platform that connects donors, volunteers, and beneficiaries while promoting the foundation's vision of creating a better and more inclusive society.
